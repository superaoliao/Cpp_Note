# P1443 马的遍历

## 题目描述

有一个 n * m 的棋盘，在某个点 (x, y) 上有一个马，要求你计算出马到达棋盘上任意一个点最少要走几步。

## 输入格式

输入只有一行四个整数，分别为 n, m, x, y。

## 输出格式

一个 n * m 的矩阵，代表马到达某个点最少要走几步（不能到达则输出 -1）。

## 输入输出样例 #1

### 输入 #1

```
3 3 1 1

```

### 输出 #1

```
0 3 2    
3 -1 1    
2 1 4    
```

## 说明/提示

### 数据规模与约定

对于全部的测试点，保证 1 <= x <= n <= 400，1 <= y <= m <= 400。

2022 年 8 月之后，本题去除了对输出保留场宽的要求。为了与之兼容，本题的输出以空格或者合理的场宽分割每个整数都将判作正确。

```c++
#include<bits/stdc++.h>
using namespace std;
int g[405][405];//棋盘
int p[160010][3];//前面的中括号内表示进行到第几个位置，而后面的表示是这个的x还是y
int dx[9] = {0,2,1,-1,-2,-2,-1,1,2};//两个方向移动的数组
int dy[9] = {0,1,2,2,1,-1,-2,-2,-1};
int x,y,n,m,tx,ty;
int h = 1,t =1;//h和t分布为头和尾的指针，h代表现在要进行判断八个方向是否有可走 的位置的第几个，t代表到当前h为止总共有多少可走且标记了的位置
int main()
{
    cin>>n>>m;
    cin>>x>>y;
    p[1][1] = x;//1为x，2为y
    p[1][2] = y;
    for(int n1 = 1;n1<=n;n1++)
    {
        for(int n2 = 1;n2<=m;n2++)
        {
            g[n1][n2]=-1;//先将输入的格子初始化为-1（方便输出）
        }
    }
    g[x][y] = 0;//（起点为0）
    while(h<=t)//当h超过了t就代表没有能走的位置，并且h试了所又的t标记的点
    {
        for(int n3 = 1;n3<=8;n3++)//走八个方向，都试一遍
        {
            tx=p[h][1]+dx[n3];
            ty=p[h][2]+dy[n3];
            if(g[tx][ty]==-1)//里面还可以加上&&...防止数组越界
            {
                t++;//发现一个能走就用t标记
                p[t][1] = tx;
                p[t][2] = ty;
                g[tx][ty] = g[p[h][1]][p[h][2]] + 1;//对移动前的位置的步数加一，代表当前步数
            }
        }
        h++;
    }   
    for(int n4 = 1;n4<=n;n4++)
    {
        for(int n5 = 1;n5<=m;n5++)
        {
            cout<<g[n4][n5]<<" ";
        }
        cout<<endl;
    }
}
```
